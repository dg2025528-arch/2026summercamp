# 🎬 YouTube 자막 요약 및 관련 영상 추천 웹앱

YouTube 영상 링크를 입력하면 자막을 분석해 **핵심 내용을 요약**하고, **관련 영상을 추천**하는 Streamlit 웹 애플리케이션입니다.

추천 과정에서는 영상 텍스트를 **TF-IDF로 벡터화**한 뒤 **코사인 유사도**를 계산합니다. 이후 조회수, 좋아요 수, 업로드 후 경과 일수를 함께 반영해 최종 추천 순위를 정합니다. 분석 결과는 CSV로 내려받아 **Orange3에서 유사도와 군집을 시각화**할 수 있습니다.

> 연구 주제: **TF-IDF와 코사인 유사도를 활용한 YouTube 자막 요약 및 콘텐츠·인기도 기반 영상 추천 시스템**

## ⚙️ 작동 원리

### 1. YouTube 영상 입력
사용자가 분석할 영상 URL을 입력하면 URL에서 영상 ID를 추출합니다.

```text
https://www.youtube.com/watch?v=VIDEO_ID
```

### 2. 자막 수집
자막은 다음 우선순위로 선택합니다.

1. 한국어 자막
2. 영어 자막
3. 그 외 사용 가능한 자막

자막이 없는 영상은 제목과 설명으로 내용을 파악합니다.

### 3. 자막 전처리
다음 요소를 제거하거나 정리합니다.

- 불필요한 공백, URL
- 음악, 박수, 웃음 등의 자막 표시
- 일부 특수문자
- 한국어 및 영어 불용어

### 4. TF-IDF 기반 핵심 문장 추출
자막을 문장 단위로 나누고 문장별 TF-IDF 점수를 계산합니다. 점수가 높은 단어를 많이 포함한 문장을 핵심 문장으로 선택합니다. 새 문장을 만드는 생성 요약이 아니라 기존 자막에서 고르는 **추출 요약**입니다.

### 5. AI 요약
추출한 핵심 문장과 핵심어, 자막 일부를 Groq API(`openai/gpt-oss-20b`)에 전달해 설정한 문장 수로 요약을 생성합니다.

### 6. 관련 영상 검색
후보 영상의 제목, 설명, 채널명, 조회수, 좋아요 수, 업로드 날짜, 썸네일을 수집합니다.

### 7. 코사인 유사도 계산
입력 영상의 자막과 후보 영상의 제목·설명을 TF-IDF 벡터로 변환하고, 두 벡터 사이의 코사인 유사도를 계산합니다. 1에 가까울수록 내용이 유사합니다.

### 8. 인기도 보정
오래된 영상이 조회수에서 유리해지는 문제를 줄이기 위해 **일평균 조회수**를 사용합니다. 조회수와 좋아요 수는 영상마다 차이가 크므로 **로그 변환**과 **최소-최대 정규화**를 적용합니다.

### 9. 최종 추천 점수

```text
Score = 0.7 × S + 0.2 × V + 0.1 × L
```

- `S`: 코사인 유사도
- `V`: 정규화된 일평균 조회수
- `L`: 정규화된 좋아요 수

## 🧪 평가 방법

세 가지 추천 방식을 비교합니다.

- **모델 A**: 조회수만 사용
- **모델 B**: 코사인 유사도만 사용
- **모델 C**: 코사인 유사도 + 일평균 조회수 + 좋아요 수 결합

상위 5개 추천 영상의 관련성을 다음 기준으로 평가합니다.

| 평가 | 점수 |
|---|---:|
| 입력 영상과 관련 있음 | 2점 |
| 어느 정도 관련 있음 | 1점 |
| 관련 없음 | 0점 |

각 모델의 상위 5개 평균 점수를 비교해 결합 방식의 효과를 분석합니다.

## ⚠️ 한계점

- 모든 영상에 자막이 있는 것은 아닙니다.
- 자동 생성 자막에는 오류가 포함될 수 있습니다.
- TF-IDF는 동의어와 문맥적 의미를 충분히 이해하지 못합니다. 뜻이 반대여도 단어가 겹치면 유사도가 높게 나올 수 있습니다.
- 후보 영상은 처리 속도를 위해 제목과 설명으로만 비교하며, 실제 내용을 완전히 반영하지 않을 수 있습니다.
- 좋아요 수가 비공개인 경우 0으로 처리됩니다.
- YouTube Data API에는 일일 할당량 제한이 있습니다.
- Groq 무료 플랜은 분당 8,000토큰 제한이 있어 입력 자막을 약 4,000자로 줄여 요청합니다. 연속 분석 시 1분 정도 간격이 필요합니다.
- 서로 다른 언어의 영상은 정확한 유사도 비교가 어렵습니다.
